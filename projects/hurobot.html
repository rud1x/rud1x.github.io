О проекте

HURObot — это многофункциональный Telegram-userbot, созданный для управления аккаунтами, автоматизации и OSINT-исследований. Проект распространяется как Open Source и доступен на GitHub [citation:4].

Основные возможности

  • 🔐 Управление аккаунтами: мультиаккаунтность, 2FA, сессии
  • 💾 Работа с медиа: автосохранение T-медиа, сжатие изображений
  • 💥 Спам-инструменты: рассылки, стикер-бомбы, краш-атаки
  • 🕵️ OSINT: геолокация IP, пробив номеров/почт, WHOIS доменов
  • ⚡ Утилиты: сокращение ссылок, экспорт чатов, анимация текста

Примеры команд

.osint [значение] — проверка IP/номера/почты,
.save — сохранить самоудаляющийся файл,
.tagall — упомянуть всех участников чата,
.short [URL] — сократить ссылку [citation:4].
