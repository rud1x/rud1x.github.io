NeoShell

Управляй своим ПК с телефона через Wi-Fi

Год 2026
Стек Python, PyQt6, Android
Лицензия GPL-3.0

О проекте

NeoShell превращает твой телефон в полноценный пульт управления для Windows-ПК. Открой приложение, отсканируй QR-код — и всё готово. Без облачных зависимостей, только локальный Wi-Fi [citation:6].

Ключевые возможности

  • 📱 Нативный Android APK с QR-сканером
  • ⚡ Мгновенное управление: блокировка, выключение, перезагрузка, сон
  • 🚀 Запуск любых приложений с ПК
  • 🎵 Медиа-контроль: play/pause, следующий, предыдущий
  • 🔐 Безопасный доступ с авторизацией по ключу
  • 📶 Работает офлайн — только локальный Wi-Fi

Установка

1. Скачай NeoShell.apk из Releases
2. Установи на телефон (разреши установку из неизвестных источников)
3. Открой NeoShell → нажми + → сканируй QR или введи данные вручную [citation:6]
