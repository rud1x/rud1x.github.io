Год 2026
Стек Python, requests

О проекте

gitfetch — минималистичная CLI-утилита для просмотра статистики GitHub-профиля в стиле fastfetch/neofetch. Показывает звёзды, коммиты, подписчиков и другую полезную информацию прямо в терминале с ASCII-логотипом.

Возможности

  • 🔥 Без токена — использует публичный GitHub API
  • 📦 Кэш на 30 минут — экономит лимиты API
  • 🎨 Оформление в стиле fastfetch с ASCII-логотипом
  • 📁 Полностью настраивается через JSON
  • 🐧 Кроссплатформенность — Linux, macOS, WSL
  • 🎯 Ноль зависимостей — только Python и requests

Установка

git clone https://github.com/rud1x/gitfetch.git && cd gitfetch && chmod +x install.sh && ./install.sh

Использование

gitfetch --reg rud1x — зарегистрировать свой username
gitfetch — запуск с сохранённым пользователем
gitfetch torvalds — статистика конкретного пользователя
gitfetch --no-cache — принудительное обновление
